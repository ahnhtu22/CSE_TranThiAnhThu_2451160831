# Ghi chú quan trọng khi làm bài tập React

1. **Thuộc tính HTML:** Đổi `class` thành `className`, `for` thành `htmlFor`.
2. **Đóng thẻ:** Mọi thẻ đơn (như `<img>`, `<input>`) đều BẮT BUỘC phải có dấu `/` ở cuối (vd: `<img />`).
3. **Luồng React (Flow):** User action → setState → re-render → UI cập nhật.
4. **Biến JSX:** Dùng cặp ngoặc nhọn `{}` để bọc các biến JavaScript, biểu thức toán học hoặc toán tử 3 ngôi (Ternary) khi muốn hiển thị ra UI.
