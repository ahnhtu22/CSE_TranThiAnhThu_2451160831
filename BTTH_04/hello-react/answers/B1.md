# Câu hỏi Tier 0

**1. File `.jsx` khác gì file `.js`?**
File `.jsx` (JavaScript XML) cho phép viết cú pháp giống hệt HTML trực tiếp bên trong file JavaScript. Nó giúp việc tạo giao diện trực quan hơn. Khi chạy, Vite/Babel sẽ tự động dịch các thẻ này thành code JavaScript thuần.

**2. Tại sao phải `export default App`?**
Để biến component `App` thành một module độc lập. Các file khác (như `main.jsx`) có thể `import` nó vào và sử dụng để hiển thị lên trình duyệt.

**3. Thử xóa `export default` → chuyện gì xảy ra?**
Trình duyệt sẽ báo lỗi và trang web bị sập trắng. Lý do là file `main.jsx` không thể tìm thấy component nào được xuất ra từ file `App.jsx` để render.
